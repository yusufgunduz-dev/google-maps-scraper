# Security Policy / Güvenlik Politikası

## English

### Supported versions
Only the latest commit on `main` receives fixes.

### Reporting a vulnerability
Please **do not open a public issue** for security problems. Email **gunduzy718@gmail.com** with the subject
`[SECURITY] google-maps-scraper`, and include the affected file or feature, steps to reproduce and the impact.
You can expect an acknowledgement within 7 days.

This tool automates a browser and can message people through WhatsApp Web. Report vulnerabilities privately. Do not use the tool to collect or contact people without a lawful basis.

## Türkçe

### Desteklenen sürümler
Yalnızca `main` dalındaki son sürüm düzeltme alır.

### Güvenlik açığı bildirimi
Güvenlik sorunları için **herkese açık issue açmayın**. **gunduzy718@gmail.com** adresine `[SECURITY] google-maps-scraper`
konusuyla e-posta gönderin; etkilenen dosya veya özelliği, yeniden üretme adımlarını ve etkisini yazın.
7 gün içinde yanıt vermeyi hedefliyoruz.

Bu araç bir tarayıcıyı otomatikleştirir ve WhatsApp Web üzerinden kişilere mesaj gönderebilir. Güvenlik açıklarını özel olarak bildirin. Aracı, hukuki dayanağı olmadan kişi toplamak veya onlara ulaşmak için kullanmayın.
